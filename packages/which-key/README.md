# Which Key

Browse and search the current application's menu bar items with keyboard shortcuts.

- **Search Mode** — fuzzy search across the menu-bar-owning app's menus (title and full path) with relevance ranking, pinned favorites, check marks, and shortcut display. Run items, open an item's top-level menu (Show Menu), or remap shortcuts via App Shortcuts (NSUserKeyEquivalents).
- **Action Mode** — type a key sequence (e.g. `sn`) to trigger a configured menu action. `:` enters action mode, `/` returns to search.

Pinned items live in `~/.config/which-key/pins.json`, remap records in `~/.config/which-key/remaps.json`.
